## 📋 Descripción

Este proyecto es el portafolio oficial del artista plástico **J. León C.**, diseñado para exhibir su obra (Óleo, Mixta, Grabado) a través de una interfaz minimalista, elegante y de alto rendimiento.

El sitio no solo funciona como galería, sino como una **experiencia interactiva**, incluyendo un módulo de generación de arte algorítmico que permite a los visitantes crear y descargar obras digitales basadas en su nombre.

## ✨ Características Clave

- **Arquitectura de Islas (Astro Islands):** Hidratación parcial para un rendimiento óptimo (100/100 Lighthouse).
- **Diseño Responsivo & Fluido:** Maquetación con **Tailwind CSS** que se adapta desde móviles hasta pantallas 4K.
- **Galería Masonry (Tipo Pinterest):** Visualización de obras sin recortes, respetando la proporción original de cada pieza.
- **Lightbox Nativo:** Visualización de detalles y fotografía de perfil en alta resolución sin librerías pesadas.
- **Módulo "Name Art Generator":**
  - Algoritmo propio en **Vanilla JS** y **HTML5 Canvas**.
  - Generación procedural de arte abstracto basado en cadenas de texto (nombres).
  - Modo de fusión `multiply` para efectos de acuarela digital.
  - Función de descarga directa en PNG.
- **View Transitions:** Navegación suave entre secciones sin recargas completas (SPA feel).

## 🛠️ Stack Tecnológico

- **Core:** [Astro v5](https://astro.build/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Lenguajes:** TypeScript / JavaScript (ES6+)
- **Despliegue:** Netlify (CI/CD desde GitHub)

## 🚀 Instalación y Despliegue Local

Si deseas clonar y ejecutar este proyecto localmente:

1.  **Clonar el repositorio:**

    ```bash
    git clone [https://github.com/abraham-oj/J-Leon-galeria.git](https://github.com/abraham-oj/J-Leon-galeria.git)
    ```

2.  **Instalar dependencias:**

    ```bash
    npm install
    ```

3.  **Ejecutar servidor de desarrollo:**
    ```bash
    npm run dev
    ```
